# Banking App Frontend

Vue frontend for the Banking App login flow.

## Tech Stack

- Vue 3
- Vite
- Pinia
- Vue Router
- Axios

## Run

```bash
npm install
npm run dev
```

By default, the frontend calls the backend directly at:

```text
http://localhost:8090
```

Set `VITE_API_URL` if the backend runs on a different origin.
